# 《残响大篷车 · Circus Caravan》九大地区「魔物娘」图鉴设计文档（基础捕捉版）

> **文档说明**：本文档延续《残响大篷车》奇幻生物图鉴的结构标准，参考经典日式魔物娘作品（如人外异种族生态、半人化魔物娘属性、反差萌与种族生活习性）并融入本作**「废土暖灯马戏团」**基调，为 **9 大地区及对应地形** 各设计 **3 种** 特殊可捕捉/收编的魔物娘模板（共 27 种）。本阶段**暂不考虑进阶形态**，聚焦基础捕获、驯养、马戏演出与大篷车日常生态。

---

## 一、数据结构映射与「魔物娘」特殊规则建议

魔物娘在底层仍复用 **3.6 `BeastSpecies` / `Beast` 系统**（通过 `isMonsterGirl: true` 或 `category: 'monstergirl'` 区分），在保留「捕捉网驯服、兽笼车厢占格、喂养与上台演出」核心循环的同时，增加符合人外美少女特性的轻量化设计：

```ts
export interface BeastSpecies {
  id: string;
  name: string;
  category: 'beast' | 'monstergirl';
  regionId: RegionId;
  habitats: TerrainType[];
  element: BeastElement;       // 'starlight' | 'flame' | 'frost' | 'spore' | 'iron' | 'void'
  baseCageCost: 1 | 2;         // 占「改装兽笼/魔物娘软卧厢」格数（蛇尾/人马/花裙等大型下肢占 2 格）
  baseCaptureDifficulty: 1 | 2 | 3 | 4 | 5;
  baseAuctionValue: number;    // 基础拍卖底价（注：魔物娘具有知性，拍卖会引发极强的道德与士气代价）
  actTags: ActTag[];           // 'acrobatics' | 'beast_tame' | 'illusion' | 'comedy' | 'music' | 'flame'

  diet: {
    dailyFodder: number;       // 常规魔物娘吃 fodder，但部分兼食人类口粮 rations 或机油 fuel
    altFeed?: string;
  };
  resourceYield?: {
    supplyKey: keyof CircusState['supplies'];
    amountFormula: string;
    note: string;
  };
  passiveSkill: {
    name: string;
    effect: string;
  };
}
```

### 1. 人类帝国 · 圣徽皇土 (`empire_heart`)

#### ① 人马骑兵娘 · 佩妮洛 (`mg_centaur_penelope`)
- **栖息地形**：`road`（旧帝国官道）、`wasteland`（废农田）
- **基础属性**：元素 `iron` ｜ 格数 `2 格` ｜ 捕捉难度 `★★★☆☆` ｜ 基础底价 `850 G` ｜ 擅长 `acrobatics`、`beast_tame`
- **外貌**：上半身是扎着棕色高马尾、身着磨损皇家轻胸甲的英气少女，下半身是健美修长的栗色骏马身躯，马蹄上钉着磨得发亮的旧黄铜蹄铁。
- **习性**：前帝国仪仗骑兵团走散的末裔，有着略显死板的骑士礼仪，对梳理马尾和擦拭马鞍极度执着；非常害怕狭小的帐篷门框，进出经常卡住。
- **表演能力**：马戏团「马背杂技」的灵魂支柱——能一边围绕舞台高速疾驰，一边背负两名杂技演员完成叠罗汉与跳火圈，极受人类帝国旧民喜爱。
- **战斗能力**：重装突击手。「圣徽骑枪冲锋」附带高额击退与破盾效果，能直接冲散拦路抢劫的武装散兵。
- **所需食物**：每日 `1` 份 `fodder` + 少量胡萝卜/苹果（可额外投喂 `rations` 提升心情）。
- **产出资源**：无实体产出。
- **被动增益 —【皇家仪仗步态】**：协助拉车行进时，大篷车在 `road`（连通道路）上的移动速度 `+15%`，且降低马车颠簸对乘客的疲劳感。

#### ② 无头骑士娘 · 赛尔蒂丝 (`mg_dullahan_celtis`)
- **栖息地形**：`ruin`（古堡/教堂废墟）、`warzone`（战火边缘）
- **基础属性**：元素 `void` ｜ 格数 `1 格` ｜ 捕捉难度 `★★★☆☆` ｜ 基础底价 `920 G` ｜ 擅长 `comedy`、`illusion`
- **外貌**：穿着改制过的黑银哥特风旅途礼服，脖颈断口处升腾着柔和的淡紫色幽冥冷焰；平时把戴着笑脸小丑面具（或自己真正精致苍白、红瞳）的头颅夹在左臂下，心情好时会换上发光南瓜灯罩。
- **习性**：看似阴森其实是个超级天然呆且极其讲礼貌的姑娘，一紧张就会不小心把自己的头掉在地上滚走，然后盲目摸黑满地找头。
- **表演能力**：荒诞黑色幽默的天花板——在舞台上与小丑上演「真假大变活头」「把自己脑袋当保龄球抛接」等绝活，既吓人又令人捧腹大笑。
- **战斗能力**：不惧伤痛的前排斩击手，释放「幽冥斩」并有概率赋予敌方【战栗】状态。
- **所需食物**：每日 `1` 份 `fodder`（其实不需要进食消化，只是喜欢用“头”咀嚼甜点品尝味道后排进灵火里）。
- **产出资源**：每周从幽冥灵火凝结出不灭冷光蜡油，每 3 日产出 `+1 props`（舞台特效蜡烛）。
- **被动增益 —【无畏夜行】**：停驻或行军经过 `warzone` 交火区时，大篷车成员不会因炮火与亡灵氛围产生额外恐慌与士气掉落。

#### ③ 史莱姆修女娘 · 蜜露 (`mg_slime_milly`)
- **栖息地形**：`ruin`（废弃修道院）、`road`（驿站旁泥地）
- **基础属性**：元素 `spore` ｜ 格数 `1 格` ｜ 捕捉难度 `★☆☆☆☆` ｜ 基础底价 `480 G` ｜ 擅长 `comedy`、`illusion`
- **外貌**：全身由半透明蜂蜜琥珀色高弹力凝胶构成的娇小少女，头顶歪戴着一块干爽的亚麻修女头巾，透明腹腔里隐约可见两枚吞下去没吐出来的闪亮铜币和几朵干花。
- **习性**：极度粘人的小太阳，喜欢紧紧抱住刚修好的车轮或团员的胳膊；为了保持人形经常偷偷喝水，天气太干燥时会缩成一滩摊平的橘子果冻。
- **表演能力**：可以任意把双臂拉长成弹簧彩带、变成巨大蹦床接住高空跌落的杂技员，或者把自己整个人吹成发光的透明气球飘在观众头顶。
- **战斗能力**：物理伤害海绵。「凝胶包裹」可无伤困住小型暴走野兽，大幅降低其挣扎反抗率（捕猎极佳）。
- **所需食物**：每日 `1` 份 `fodder`（偏爱糖水、水果皮和废旧木屑）。
- **产出资源**：吞吐清洁金属锈迹后可回收可用铜铁部件，每 3 日产出 `+1 spareParts`。
- **被动增益 —【蜜胶舒缓】**：营地休息时帮助团员擦洗伤口与消除肌肉酸痛，全团每日额外恢复 `4` 点疲劳（`fatigue`）。

### 2. 魔法都市 · 浮空塔废都 (`arcane_city`)

#### ① 魔导书妖精娘 · 菲莉娅 (`mg_grimoire_philia`)
- **栖息地形**：`ruin`（破碎魔法学院）
- **基础属性**：元素 `starlight` ｜ 格数 `1 格` ｜ 捕捉难度 `★★☆☆☆` ｜ 基础底价 `760 G` ｜ 擅长 `illusion`、`music`
- **外貌**：身材娇小纤细的银发少女，穿着宽大拖地的旧学院法袍，背后浮游着一对由翻动着的古旧羊皮书页构成的双翼，发丝间别着一支自己会记笔记的羽毛笔。
- **习性**：前代大魔导师遗留典籍孕育出的书灵，重度知识强迫症患者。一听到有人讲错历史或念错咒语就会气鼓鼓地打喷嚏，喷出一堆发光的错误勘误符文。
- **表演能力**：能把古老童话书的内容直接「具象化投影」在剧场半空中，配合柔和的翻页声与八音盒旋律，打造废土中最治愈的立体绘本剧场。
- **战斗能力**：远程法术辅助。「静音页障」封印野生魔法生物的危险技能，保护车厢不受魔法余波破坏。
- **所需食物**：每日 `1` 份 `fodder`（喜食墨水露与干燥魔草花瓣）。
- **产出资源**：每日掉落多余的幻彩折叠纸鹤，每 2 日产出 `+1 props`。
- **被动增益 —【废都考据】**：在「侦查聚落」或探索 `ruin` 遗迹时，有更高概率发现隐藏的历史秘闻或额外物资，且幻术表演消耗 `fuel` 减少。

#### ② 晶体石像鬼娘 · 格蕾丝 (`mg_gargoyle_grace`)
- **栖息地形**：`mountain`（浮空碎石带）、`ruin`（高塔断崖）
- **基础属性**：元素 `iron` ｜ 格数 `1 格` ｜ 捕捉难度 `★★★☆☆` ｜ 基础底价 `820 G` ｜ 擅长 `acrobatics`、`illusion`
- **外貌**：皮肤呈温润浅灰大理石质感的冷艳少女，背生一对镶满紫色水晶簇的蝙蝠石翼，额头长着一对小巧精致的山羊弯角，常穿着紧身哥特护胸衣。
- **习性**：典型傲娇卫士。白天喜欢一动不动蹲在最高那辆车厢的车顶充当装饰石雕打瞌睡；如果有人敢说她“很重”，会气得扇动水晶翅膀把对方屋顶掀翻。
- **表演能力**：先伪装成毫无生气的舞台雕塑迷惑观众，在音乐高潮瞬间碎裂石粉化蝶腾空而起，接上高空单翼悬停杂技，惊艳度拉满。
- **战斗能力**：高物防空降重锤。「宝石俯冲」对敌方造成眩晕与破甲。
- **所需食物**：每日 `1` 份 `fodder`（偏爱含水晶碎屑的矿盐块，食量极小）。
- **产出资源**：无实体产出。
- **被动增益 —【高塔守望】**：日夜驻守大篷车最高处，车队遭遇强盗夜袭或野兽伏击的概率降低 `25%`，交涉/避险先手判定提升。

#### ③ 星灵猫娘 · 露米娜 (`mg_caitsith_lumina`)
- **栖息地形**：`wasteland`（晶石荒地）、`road`（魔导大道）
- **基础属性**：元素 `starlight` ｜ 格数 `1 格` ｜ 捕捉难度 `★★☆☆☆` ｜ 基础底价 `790 G` ｜ 擅长 `acrobatics`、`comedy`
- **外貌**：拥有半透明星夜色猫耳与两条分叉长尾巴的元气少女，眼眸一金一蓝如星云宝石，披着一件缀满失效小铃铛的破旧天鹅绒魔术师披风。
- **习性**：纯粹的享乐主义捣蛋鬼，见到毛线球、亮晶晶的金币或者光点就会彻底丧失理智扑上去；但只要被揉下巴就会发出像发动机一样的呼噜声。
- **表演能力**：擅长「猫步走钢丝」「无中生有扑克牌雨」以及和演员逗趣互动的「魔术帽大逃脱」，笑声与掌声制造机。
- **战斗能力**：超高闪避与暴击。「星爪连击」适合快速削减猎物血量而不致死。
- **所需食物**：每日 `1` 份 `fodder`（最好偶尔加餐一条鱼干）。
- **产出资源**：无实体产出。
- **被动增益 —【猫妖财运】**：每场演出结束时的观众额外打赏（`tipBonus`）提升 `20%`，且更容易在货站刷出高溢价单。

## 四、魔物娘专属系统联动与道德抉择补充

1. **宿位与车厢改装情感线**：
   - 魔物娘虽共用 `maxCageSlots`（兽笼格位上限），但随着信赖度/驯服度（`tameness`）提升，可在 `workshop` 将普通铁笼升级为**「软垫蕾丝卧铺厢」**或**「水族恒温玻璃车厢」**，防止冷血蛇女冻僵或人鱼娘缺水，大幅提升她们的 `appeal`（观赏度）。
2. **「拍卖行」的残酷试金石（末世人文抉择）**：
   - 在架构文档 3.6 中，玩家可将高价生物送上 `AuctionListing` 拍卖行迅速凑齐隐居资金（例如一条龙姬或传奇魔物娘能直接卖出数千金币）。
   - 然而，由于魔物娘拥有**完整知性与深厚日常羁绊**，若玩家选择把已驯服的魔物娘卖给灰烬军团（`ash_legion`）或锈蚀黑市（`rust_syndicate`），不仅会遭到黎明圣教（`dawn_order`）的严厉谴责与大幅降好感，还会让全团人类演员（`Performer`）陷入强烈的罪恶感与信任危机（大幅扣除 `morale` 与 `bond`），甚至可能触发某些善良演员的离队事件。
3. **「隐居结局」的温馨归宿**：
   - 如果玩家拒绝拍卖她们、一路把这群流离失所的人外少女带到最终的「世外净土（`sanctuary`）」，她们将全部出现在 `RetirementProgress.ending.accompanyingBeasts` 专属尾声中——雪女娘经营永不融化的刨冰摊、蜘蛛娘继续给退隐团员缝新衣、斯芬克丝每天晒着太阳给村里的孩子们出谜语，共同构成荒芜末世里最温暖的童话结局。
