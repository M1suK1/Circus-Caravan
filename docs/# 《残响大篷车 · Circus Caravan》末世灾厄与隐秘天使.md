# 《残响大篷车 · Circus Caravan》末世灾厄与隐秘天使恶魔系统设计文档

> **文档定位**：为《残响大篷车》世界注入更深层的末世紧迫感与悬疑推理驱动力——大陆的衰败并非单纯的自然老化，而是由**九大地区各自面临的独特「末世灾厄」**，以及暗中伪装成普通人类、彼此博弈的**「潜伏天使与伪装恶魔」**所共同推动。

---

## 一、核心世界观定位与数据结构扩展

### 1.1 关键区分：恶魔 vs 魔王军魔物娘
为避免世界观混淆，本作明确区分两类截然不同的存在：
- **魔王军魔物娘**：真实存在的人外种族（牛头人、独眼、蜘蛛等），有肉眼可见的非人特征，因反抗人类帝国奴隶制而结成解放军；
- **隐藏恶魔（Abyssal Devils）与潜伏天使（Veiled Angels）**：高维超自然存在。大灾变后天界与深渊通道破碎，少数残存的天使与恶魔披上**完全与常人无异的人类皮囊**潜伏于聚落、商队或乘客之中。
  - **潜伏天使**：神力受损且受“不得强行干涉凡人自由意志”的戒律制约，只能化身不起眼的小人物，暗中调查灾厄根源、修复局部破损，等待能汇聚人心微光的“外力（大篷车）”协助破局；
  - **伪装恶魔**：极度擅长扮演掌权者、商人、向导或神职人员，故意挑拨人类帝国、军阀与魔王军的仇恨，借奴隶贸易与绝望恐慌喂养所在区域的「灾厄」，阻止世界复苏。

### 1.2 数据结构补充建议（接入 `CircusState.world`）

```ts
export type HiddenTrueNature = 'human' | 'angel' | 'devil';

export interface RegionCalamity {
  id: string;
  regionId: RegionId;
  name: string;
  /** 灾厄恶化等级 1(微兆) -> 2(蔓延) -> 3(危境) -> 4(绝境) -> 0(已平息) */
  severity: 0 | 1 | 2 | 3 | 4;
  progress: number;           // 0–100，随天数自然增长，恶魔活跃时加速，巡演希望值可局部延缓
  resolved: boolean;
  /** 本区隐藏的天使与恶魔 NPC ID（指向 WorldNpc 或特定 PassengerContract） */
  angelNpcId: string;
  devilNpcId: string;
  /** 玩家已收集到的破案线索标签 */
  discoveredClues: string[];
}

export interface HiddenAgentMeta {
  trueNature: HiddenTrueNature;
  coverOccupation: string;    // 表面人类职业
  tells: string[];            // 3条可被侦破的细微破绽
  angelRequest?: string;      // 天使需要大篷车配合的破局条件
  devilTemptationGold?: number; // 恶魔被识破时可能开出的“封口费/堕落交易金”（诱惑玩家隐居资金）
}
```

## 三、「马戏团式侦破」：如何找到伪装的天使与恶魔

玩家并不是侦探或审判官，而是**流浪马戏团团长**。线索获取完全融入大篷车日常玩法，不强加繁琐小游戏：

1. **【舞台共鸣试金石】**：在聚落开演时，潜伏的天使与恶魔常常混在观众席里。
   - **对恶魔的刺激**：播放圣洁的《晨曦安魂曲》、展出星光精灵（`starlight`）或太阳不死鸟幻象时，台下某位看似威严的“大人物”会出现**捂耳冷笑、影子扭曲或提前离席**的异常日志提示；
   - **对天使的共鸣**：当马戏团在绝望村落成功大幅拉升希望值（`hopeGain`）时，角落里默默鼓掌流泪的“普通老人/学徒”会落下**散发微弱暖光的羽毛状碎屑或古怪谢礼**。
2. **【搭车旅途与篝火破绽 (`PassengerContract` + VN)】**：
   - 当怀疑对象作为普通乘客坐上大篷车，或成为临时雇员时，会在旅途对话中暴露细节破绽（例如：从不碰普通热食、在雪地不喘白气、面对被奴役的猫娘露出贪婪舔唇、或深夜对着月亮独自修补破损地图）。
3. **【伙伴直觉雷达】**：
   - 团队中 `insight` 属性高的**荒野斥候 (`scout`) / 幻术师 (`illusionist`)**，以及具有灵性感知的随行生物/魔物娘（如**星灵猫娘、虚空折纸鸦、深海灯笼鱼娘、苍穹鹿角森灵**），会在日志里主动提醒团长：*“那位先生身上没有心跳声，而且灯油火焰在躲着他。”*
4. **【二选一或双向破局】**：
   - **协助天使**：把收集到的恶魔罪证交给潜伏天使，或在马戏演出高潮时配合天使布置特定道具（如星光草、极光冰晶、希望欢呼声），助其短暂恢复神力驱逐恶魔、彻底平息该区灾厄；
   - **恶魔的诱惑（终极道德抉择）**：当你当面识破伪装恶魔时，狡猾的恶魔往往不会立刻硬拼，而是低声诱惑急需隐居资金的团长——**“别多管闲事，演完最后一场把那位天使的藏身处告诉我，这箱 15,000 金币的黄金立刻归你，够你带着团员找个山谷养老了！”**

## 四、九大地区灾厄与天使 / 恶魔详细档案

---

### 1. 人类帝国（圣徽皇土 `empire_heart`）
- **末世灾厄：【血锈饥荒与猜忌狂潮】**
  - **灾厄现象**：帝国麦田被不明赤红铁锈斑吞噬，颗粒无收；吃下微毒“血锈麦”的民众逐渐陷入歇斯底里的被迫害妄想，认为灾难全是魔物娘和外乡流浪者下的毒咒。
  - **恶化阶段**：`Lv.1` 口粮微涨 → `Lv.2` 村庄开始拒演、盘查亚人奴隶证 → `Lv.3` 暴民自发围攻马车、抓捕野生魔物娘火刑 → `Lv.4` 帝国全境农田绝收，`warzone` 叛乱四起。
- **潜伏天使 ·「盲眼施粥老牧师 · 亚伯」**
  - **伪装**：穿着补丁灰袍、在边境教堂废墟免费熬稀粥的老瞎子。
  - **破绽特征**：虽然双目缠满绷带，却能在漆黑夜里一滴不漏地把热粥盛进每个饥饿孩童和流浪犬娘的碗里；那口永远熬不干的铁锅底隐约铭刻着天使语微光，但他自己从来一口不喝。
  - **诉求**：希望马戏团用一场不带偏见的欢乐演出平息暴民怒火，并帮忙从帝国税官手中夺回被私吞扣押的纯净麦种。
- **伪装恶魔 ·「圣徽钦差铁面税官 · 冯·克劳斯」**
  - **伪装**：骑着高头大马、随身带着皇家印信与奴隶烙铁的冷酷贵族特使。
  - **破绽特征**：所到之处粮仓必被“征缴后离奇失火”，极其热衷宣判低阶亚人公民贬籍为奴，马靴走过枯草时会留下焦黑血锈鞋印。
  - **阴谋与破局**：他故意把魔灾源头嫁祸给魔物娘挑动帝国屠村。在圣徽主城当众揭穿他私藏灾厄菌种、或配合亚伯牧师在广场舞台投影出他的恶魔角影，即可引发民众觉醒将其驱逐/讨伐，平息血锈灾。

### 2. 魔法都市（浮空塔废都 `arcane_city`）
- **末世灾厄：【魔网崩解与坠落乱流】**
  - **灾厄现象**：支撑浮空残塔的地下魔脉出现恶性空洞，原本悬浮的石岛与魔法废塔开始缓慢下沉坠落；逸散的乱流让旅人产生时空错乱，魔导灯油消耗失控。
  - **恶化阶段**：`Lv.1` 夜间灯光闪烁不定 → `Lv.2` `fuel` 油耗提升 50% → `Lv.3` 行经 `mountain`/`ruin` 频遭浮石坠砸（车损剧增）→ `Lv.4` 主城塔群彻底塌陷成死亡辐射区。
- **潜伏天使 ·「落魄抄书女学者 · 瑟琳娜」**
  - **伪装**：戴着厚重破损眼镜、背着沉重羊皮卷轴在碎塔间拾荒的年轻女抄书员，总是被高阶法师们当成跑腿苦力呼来喝去。
  - **破绽特征**：她抄写的根本不是普通魔法笔记，而是用来缝合天空裂缝的古老星辰数学；受伤流出的不是鲜血而是带着星辉的液体，且对奥术水母、魔导书妖精极为亲和。
  - **诉求**：需要马戏团替她收集齐 3 处不同废塔节点的时空坐标，并在中心广场利用高空杂技与幻术师合力把“镇星棱镜”送上半空锚点。
- **伪装恶魔 ·「魔导议会首席炼金顾问 · 马尔萨斯」**
  - **伪装**：风度翩翩的白袍银发大法师，议会重启“永动大法阵”的核心倡导者。
  - **破绽特征**：提议抓捕上百名冰霜/星光系魔物娘抽干魔力当“一次性燃料棒”，每当有浮空碎石砸死平民，他袖口里都会飞出一缕只有猫娘能看见的黑紫笑脸烟雾。
  - **阴谋与破局**：所谓的“重启永动机”其实是引爆整个城市魔网的灭世炸弹。大篷车可利用虚空折纸鸦或混入实验室偷出真蓝图，当众毁掉伪造祭坛，配合瑟琳娜重定星枢。

### 3. 魔王城（焦土黑域 `demon_realm`）
- **末世灾厄：【黑日烬风与狂暴血疫】**
  - **灾厄现象**：焦土火山灰遮蔽太阳形成“黑日”，吸入滚烫黑灰的生灵心脏会被狂躁火焰灼烧，人类士兵变得嗜血疯狂，连温顺的魔物娘也控制不住野性本能互相撕咬。
  - **恶化阶段**：`Lv.1` 兽笼生物容易暴躁 → `Lv.2` 每日全团 `tameness` 与 `morale` 加速下滑 → `Lv.3` 灰烬军团与魔王军全面进入“不死不休绞肉战” → `Lv.4` 黑域彻底化作无人可活的沸腾熔炉。
- **潜伏天使 ·「沉默的焦土摆渡孤儿 · 诺亚」**
  - **伪装**：总是推着一辆吱呀作响的小木车、在交火线边缘默默收殓阵亡人类与魔物娘遗骸的哑巴瘦小少年。
  - **破绽特征**：在终年高温飘灰的焦土里，他的发梢和衣领永远一尘不染且散发微凉的清泉气味；凡是他合上眼睑的死者，脸上狰狞狂暴的表情都会瞬间化作安详微笑。
  - **诉求**：希望马戏团在战火前线两军对峙的间隙，冒险搭建临时舞台奏响一曲真正能穿透烬风的安魂欢歌（需结合高共情演员或蕾娜塔/芙萝拉），帮他唤醒一处被掩埋的净化泉眼。
- **伪装恶魔 ·「战地死士狂热军火商 · 巴尔托」**
  - **伪装**：左手装着精巧黄铜义肢、左右逢源向灰烬军团与魔王军激进派同时兜售武器与“无畏兴奋剂”的豪爽佣兵商人。
  - **破绽特征**：卖给双方的药剂瓶底都有微弱恶魔诅咒印记，无论多么惨烈的伤亡新闻都能让他激动得心跳加快、体温骤升到把酒杯烫裂。
  - **阴谋与破局**：他在暗中用狂暴炼金粉尘人为加剧黑日火山喷发，好让两边永远杀下去。截获他的货单并当着魔王军与人类溃兵的面砸碎“狂血药箱”，便能瓦解其阴谋。

### 4. 古老之森（巨木迷林 `ancient_forest`）
- **末世灾厄：【苍白菌毯与失语眠雾】**
  - **灾厄现象**：如雪般苍白的寄生菌丝悄无声息蔓延森林地面，吸入甜腻白雾的人会失去说话能力，沉入不断重复最痛苦遗憾的永眠梦境，最终身体长出树枝变成木乃伊。
  - **恶化阶段**：`Lv.1` 森林迷雾浓重 → `Lv.2` 经过 `forest` 疲劳翻倍 → `Lv.3` 树梢村落全员陷入沉睡（无法交易/无人看戏）→ `Lv.4` 整片森林化为无声白色墓园。
- **潜伏天使 ·「口吃的迷路采药笛手 · 莉莉安」**
  - **伪装**：背着竹篓、说话结结巴巴、总是在树林里迷路却手里紧握一根旧木笛的雀斑村姑。
  - **破绽特征**：她一吹起走调的小笛子，周围蔓延过来的苍白菌丝就会像怕烫一样缩回去；她随身携带的草药香囊能让昏睡的人短暂流下清醒的眼泪。
  - **诉求**：森林菌毯的核心在最深处的母菌树洞，她需要马戏团派出的抗毒/森林伙伴（如提灯孢子鹿、花冠曼陀罗娘或雪女）配合她深入净化母核，并用欢笑声叫醒沉睡的树梢村。
- **伪装恶魔 ·「温柔的林间黑店老板娘 · 玛莎夫人」**
  - **伪装**：在林间古道经营着一家挂着暖灯、永远免费送出热蘑菇甜汤的慈祥中年妇人。
  - **破绽特征**：店里从来不养猫狗（生物一靠近店门就会拼命狂吠逃跑），她煮的甜汤没有任何人见过她自己喝过一口，地下室其实藏满准备打包卖给黑市的昏睡旅人与兔娘。
  - **阴谋与破局**：她正是培育苍白菌毯的幕后黑手，靠收割沉睡者的美梦与绝望进补。抵制黑店诱惑、用火系或药师手段揭破地下室菌母，即可联手莉莉安彻底净化森林。

### 5. 极北霜壁（永冻边塞 `frost_bastion`）
- **末世灾厄：【绝对冰潮与熄火冻灾】**
  - **灾厄现象**：极地深处的反常寒潮突破防线，不仅气温跌破极限，连普通火把和车灯都莫名失去热量逐渐变冷；矿工们在清醒状态下从脚底开始慢慢冻结成晶莹冰雕。
  - **恶化阶段**：`Lv.1` 夜间需双倍 `fuel` → `Lv.2` `fuel` 消耗三倍、道路结冰翻车 → `Lv.3` 北境矿镇大批熄火冻结 → `Lv.4` 极北彻底成为冰封死域。
- **潜伏天使 ·「衣衫单薄的矿洞点灯童 · 提莫」**

### 9. 曙光裂岸（雾海港湾 `dawn_coast`）

## 五、系统联动与多结局收束

1. **大篷车不仅是生意，更是世界的「抗灾微光」**：
   - 仅仅低头赚金币也能攒够 `retirement.targetGold` 达成普通隐居（`modest` / `prosperous`），但世界会继续在九大灾厄下缓慢沉沦（`worldDecay` 飙升）。
   - 如果玩家在赶路与巡演之余，顺手调查出潜伏的恶魔、协助隐忍的天使平息各区灾厄：
     - 平息灾厄不仅会大幅削减 `worldDecay`、永久解放该地区的受苦民众与魔物娘；
     - 全部或半数以上灾厄平息后，那些留在世间的天使也会成为你们隐居山谷的远方守望者，解锁真正的**「传奇微光结局 (`legendary`)」**。
2. **「魔鬼的交易」极速通关诱惑**：
   - 面对高额隐居门槛或濒临破产危机时，如果玩家多次接受伪装恶魔开出的高价封口费与奴隶勾当，虽然能极快攒齐退休金币买下农庄，但在尾声结算时将会触发暗黑讽刺的**「余烬中的独善其身」**结局变体——马戏团虽然活了下来，但世界在背后彻底熄灭了微光，昔日善良的团员与魔物娘们也将在沉默中渐行渐远。
