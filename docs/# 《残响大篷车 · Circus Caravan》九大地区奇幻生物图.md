# 《残响大篷车 · Circus Caravan》九大地区奇幻生物图鉴设计文档（基础捕捉版）

> **文档说明**：本文档基于《残响大篷车》架构文档 **3.3（9 大奇幻地区与地形）** 与 **3.6（奇幻生物系统）** 编写，为每个大区及对应生态地形设计 **3 种** 可捕捉的基础奇幻生物模板（共 27 种）。本阶段**暂不涉及多段进阶分支**，专注于野外遭遇、捕捉、驯养、马戏演出、护航战斗及大篷车后勤生态的闭环设计。

---

## 一、数据结构映射与字段扩展建议

为支持文档中提到的「习性、地形栖息、食谱、资源产出与被动增益」，建议在 `BeastSpecies`（见架构文档 3.6）基础上补充以下轻量级设计字段（暂留 `evolutions: []`）：

```ts
export interface BeastSpecies {
  id: string;
  name: string;
  regionId: RegionId;
  /** 可在哪些微观地形格（TerrainType）扎营狩猎时遭遇 */
  habitats: TerrainType[];
  element: BeastElement;       // 'starlight' | 'flame' | 'frost' | 'spore' | 'iron' | 'void'
  baseCageCost: 1 | 2;         // 占兽笼格数（小型 1 格 / 大型 2 格）
  baseCaptureDifficulty: 1 | 2 | 3 | 4 | 5;
  baseAuctionValue: number;    // 基础拍卖底价（金币）
  actTags: ActTag[];           // 'acrobatics' | 'beast_tame' | 'illusion' | 'comedy' | 'music' | 'flame'

  /** 饮食消耗（基于 supplies 账本） */
  diet: {
    dailyFodder: number;       // 每日消耗兽料（fodder）
    altFeed?: string;          // 缺料时的替代/偏好投喂物（如零件、灯油、口粮等）
  };
  /** 可选：每日或驻扎时的资源产出 */
  resourceYield?: {
    supplyKey: keyof CircusState['supplies'];
    amountFormula: string;
    note: string;
  };
  /** 被动增益（在兽笼或驻守状态生效） */
  passiveSkill: {
    name: string;
    effect: string;
  };
}
```

## 三、分区域奇幻生物详细档案

### 1. 人类帝国 · 圣徽皇土 (`empire_heart`)
> **生态基调**：旧帝国秩序崩塌后的半农半战区，荒芜的麦田、断壁的石道与战火未熄的关隘交错。

#### ① 徽章钟雀 (`crest_bellfinch`)
- **栖息地形**：`road`（古官道）、`ruin`（教堂与庄园废墟）
- **基础属性**：元素 `starlight` ｜ 兽笼 `1 格` ｜ 捕捉难度 `★☆☆☆☆` ｜ 基础底价 `260 G` ｜ 擅长 `music`、`comedy`
- **外貌**：体型如家鸽大小，胸前羽毛天然长出暗金色的旧帝国圣徽纹路，尾羽末端是三片中空、撞击时会发出清脆风铃声的角质羽管。
- **习性**：极度迷恋金属反光和人类过去的礼乐声，常成群栖息在坍塌的钟楼里，精准模仿战前凯旋号的旋律——即便周围早已没有观众。
- **表演能力**：无需复杂排练即可与吟游诗人或小丑配合，吹奏滑稽变调的“皇家进行曲”；在帝国旧民聚落演出时，能勾起观众温暖回忆，额外提升票房打赏。
- **战斗能力**：低直接杀伤；战斗中可发出高频鸣笛声波，打断敌方施法或使野生小兽陷入短暂【迷茫】，方便投掷捕获网。
- **所需食物**：每日 `1` 份标准兽料（`fodder`），偏爱掺杂谷壳与细沙粒帮助鸣管共鸣。
- **产出资源**：每周/每3日抖落 1 份可用作亮片与铃铛的【旧徽羽饰】，折算为 `+1 props`（演出耗材）。
- **被动增益 —【遗落仪仗】**：城镇开演后，该聚落的「希望值（`hopeGain`）」额外 `+2`。

#### ② 麦穗稻草犬 (`stubble_hound`)
- **栖息地形**：`wasteland`（焦黑农田废墟）
- **基础属性**：元素 `spore` ｜ 兽笼 `1 格` ｜ 捕捉难度 `★★☆☆☆` ｜ 基础底价 `380 G` ｜ 擅长 `acrobatics`、`beast_tame`
- **外貌**：瘦长灵活的猎犬体态，皮毛与共生金黄色枯麦草纠缠在一起，眼眶与鼻尖闪烁着温顺的琥珀色丰收菌光，跑动时像一团滚过荒野的暖黄稻草堆。
- **习性**：旧农庄守护犬与麦田灵孢结合后的温和异变种。习惯在夜里巡视废墟，驱赶偷吃粮食的害鼠，对马戏团的篝火与孩子毫无敌意。
- **表演能力**：擅长「草堆大变活人」「火圈精准钻跃」等乡土亲民杂技，极受偏远村落与流民观众喜爱，几乎零怯场风险。
- **战斗能力**：敏捷型近战护卫，擅长侧翼扑咬与【缠草绊摔】，能有效拖住企图抢粮的盗匪。
- **所需食物**：每日 `1` 份 `fodder`（若兽料耗尽，可临时消耗 `1` 份团员 `rations` 中的面包屑代偿）。
- **产出资源**：无直接物资产出（会主动抓捕营地鼠虫，间接止损）。
- **被动增益 —【守望麦田】**：扎营或行军期间，大篷车每日口粮（`rations`）因受潮或鼠害导致的额外损耗归零，并降低夜间偷袭触发率 `15%`。

#### ③ 战壕铁甲蝘 (`trench_pangolin`)
- **栖息地形**：`warzone`（交火战区、战壕遗迹）
- **基础属性**：元素 `iron` ｜ 兽笼 `1 格` ｜ 捕捉难度 `★★★☆☆` ｜ 基础底价 `520 G` ｜ 擅长 `comedy`、`acrobatics`
- **外貌**：类似穿山甲的厚重生物，背部覆盖着生锈骑士盾牌般的层叠锻铁鳞片，尾巴末端是一枚圆钝的金属锤节，受惊时会缩成一颗完美的铁球。
- **习性**：靠舔食战场遗留的硝石、锈铁屑和枯根存活。性格迟钝憨厚，听见炮火反而会兴奋地缩成一团滚来滚去。
- **表演能力**：小丑节目的黄金搭档——被小丑推着当保龄球撞翻木桶塔，或者让杂技演员站在它高速旋转的背甲上保持平衡，喜剧爆笑率极高。
- **战斗能力**：顶级前排肉盾。战斗开局自动获得高额【铁壁护甲】，释放「滚动冲撞」击退敌方前排并吸收对车厢的流弹伤害。
- **所需食物**：每日 `1` 份 `fodder` + 每 3 日需额外投喂 `1` 份 `spareParts` 边角铁屑磨牙（不喂会啃车轮）。
- **产出资源**：每 4 日蜕换一次高韧性铁鳞，转化为 `+1 spareParts`（修补零件）。
- **被动增益 —【战地掩体】**：大篷车强行穿越或遭遇 `warzone` 拦截时，车厢耐久（`durability`）损失减免 `30%`。

### 2. 魔法都市 · 浮空塔废都 (`arcane_city`)
> **生态基调**：魔力溢散、引力残缺、浮石与碎裂高塔遍布，残存生灵大多被魔导残响重塑。

#### ① 折光星水母 (`prism_jelly`)
- **栖息地形**：`ruin`（学院碎塔）、`wasteland`（晶石荒地）
- **基础属性**：元素 `starlight` ｜ 兽笼 `1 格` ｜ 捕捉难度 `★★☆☆☆` ｜ 基础底价 `560 G` ｜ 擅长 `illusion`、`music`
- **外貌**：脱离水面漂浮在半空中的半透明水母，伞盖内部仿佛封存着一小片缓缓旋转的微缩星空，垂下的细长触须随风发出水晶风铃般的嗡鸣。
- **习性**：靠吸收空气中逸散的旧魔力与星光微粒为生，性格梦幻游离，受惊时会投射出附近曾经发生过的旧日幻影。
- **表演能力**：天然的「全息舞台投影仪」。能让整个篷布剧场瞬间置身于海底或星云之中，在魔法都市或贵族聚落极受追捧，大幅拉高 `illusion` 标签评分。
- **战斗能力**：非暴力支援型。触须释放柔和的【星尘致盲】，大幅降低野生怪物命中率并轻微回复己方精神/体力。
- **所需食物**：每日 `1` 份 `fodder`（偏爱研磨后的发光苔粉，极省食量）。
- **产出资源**：无实体物资产出。
- **被动增益 —【浮光省烛】**：夜场（`night`）演出及夜间赶路时，魔导灯油（`fuel`）消耗减少 `1` 单位（最低为 1）。

#### ② 虚空折纸鸦 (`voidfold_crow`)
- **栖息地形**：`road`（魔导大道）、`ruin`（法师塔废墟）
- **基础属性**：元素 `void` ｜ 兽笼 `1 格` ｜ 捕捉难度 `★★★☆☆` ｜ 基础底价 `680 G` ｜ 擅长 `illusion`、`acrobatics`
- **外貌**：通体如墨色羊皮纸折叠而成的乌鸦，翅膀内侧印满暗紫色的失效符文，每次振翅都会像纸页翻动般发出“沙沙”轻响，并留下短暂的虚空残影。
- **习性**：聪明狡黠，喜欢收集闪亮的魔晶碎片和别人遗忘的纸条。会利用微小的空间折叠闪烁躲避天敌。
- **表演能力**：幻术师的绝佳助手——能叼着道具在舞台左右瞬间“瞬移”重现，轻松实现「大变活物」与「纸牌雨魔法」等高难度视觉戏法。
- **战斗能力**：高闪避刺客。技能「空间折跃」无视地形障碍直击敌后，也能替驯兽师将麻醉网精准“闪现”盖在猎物头上。
- **所需食物**：每日 `1` 份 `fodder`（需混入少量废纸或植物灰烬）。
- **产出资源**：每日收集并吐出带有微弱幻彩的符文碎屑，相当于 `+1 props`（每 2 日一次）。
- **被动增益 —【折叠隐踪】**：行军采取「熄灯潜行避战（`evadingWar: true`）」时，被势力巡逻队发现拦截的概率额外降低 `20%`。

#### ③ 过载魔偶鼬 (`overload_ferret`)
- **栖息地形**：`mountain`（浮石裂隙）、`wasteland`（晶石荒地）
- **基础属性**：元素 `iron` ｜ 兽笼 `1 格` ｜ 捕捉难度 `★★★☆☆` ｜ 基础底价 `620 G` ｜ 擅长 `flame`、`comedy`
- **外貌**：前半身是雪白柔软的绒毛雪貂，后半段脊椎却镶嵌着一枚裸露跳动的蓝白魔导蓄能核心，尾巴像一条滋滋冒火花的铜丝线圈。
- **习性**：多动症般的精力过剩，喜欢啃咬废弃魔导管道充电，一打喷嚏就会放出一小串五颜六色的电火花，经常把自己炸成爆炸头。
- **表演能力**：天生的「电光爆竹制造机」，在舞台上追逐自己冒火花的尾巴就能逗乐全场，还能配合焰火节目制造无烟冷焰火。
- **战斗能力**：高爆发控场。「静电过载」造成范围雷电伤害并附带【麻痹】效果，大幅压低野兽闪避与反抗，是捕猎队的神级工具兽。
- **所需食物**：每日 `1` 份 `fodder`（需定期在晶石地或工坊补充少许静电）。
- **产出资源**：每日可将体内溢出的残余魔力凝结注入灯油罐，产出 `+1 fuel`（魔导灯油，每日稳定上限 1）。
- **被动增益 —【便携电容】**：工坊（`workshop`）车厢制作舞台道具或麻醉捕具时，材料消耗概率减免。

### 3. 魔王城 · 焦土黑域 (`demon_realm`)
> **生态基调**：火山灰遮天蔽日、熔岩裂谷纵横、战火与旧魔族遗产共存，极度危险但高阶价值生物富集。

#### ① 余烬幻尾狐 (`ember_fox`)
- **栖息地形**：`wasteland`（焦土黑原）
- **基础属性**：元素 `flame` ｜ 兽笼 `1 格` ｜ 捕捉难度 `★★☆☆☆` ｜ 基础底价 `640 G` ｜ 擅长 `flame`、`illusion`

## 四、生态与数值平衡补充设计

1. **饮食与补给张力**：
   - 常规 `1 格` 生物耗费 `1 fodder/日`，`2 格` 巨兽耗费 `2 fodder/日`；部分如「提灯孢子鹿」「沙漏响尾蛇」「苔背巨龟」自带局部地形减耗或反哺能力，鼓励玩家根据即将前往的大区生态调整随行生物阵容。
2. **「捕猎工具兽」与「后勤工具兽」的价值**：
   - 并非只有高 `appeal` 的华丽生物才值得留着——如提供麻痹/催眠的**过载魔偶鼬**、**深渊吞影貘**、**丝网长臂猴**能显著提高后续抓捕高星珍稀生物的成功率；而产油产零件的**气泡泥蛙**、**发条食铁鼠**、**绿洲储水驼兽**则是穷困期跨区远行的移动补给站。
3. **演出标签 (`ActTag`) 与大区受众分布**：
   - 荒凉苦寒区（`frost_bastion` / `iron_wastes`）的居民更偏爱热烈的 `flame`、`comedy` 和 `music`；废都与神秘区（`arcane_city` / `dawn_coast`）对 `illusion` 和 `starlight` 元素有天然高溢价；而高战乱区（`empire_heart` / `demon_realm`）中能够稳定护航又能登台的生物最具综合性价比。
