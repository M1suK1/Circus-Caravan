# Plan-001 · 羊皮纸冒险手稿 UI 原型与 128×128 / 10× 三级测绘地图系统

> **分支**：`superpowers/parchment-atlas-v2`
> **范围**：纯前端原型（不制作后端接口；LLM 叙事交互采用前端模拟流式/确定性预览，完整呈现交互模态框与状态面板）。

## 一、目标与核心设计约束
1. **UI 空间架构（参考 `night-sugar-office` `Shell.tsx`）**：
   - 左侧固定导航轨（`82px`，移动端 `<560px` 折叠）：`地图`、`马车`、`物资`、`记录` 4 大主功能页 + 底部快捷工坊/卡库/世界手记/叙事引擎设置/使用指南按钮。
   - 顶部仪表顶栏（`87px`）：剧团徽记、当前历法/气候、当前所在大区与三级定位、金币与隐居目标进度条、核心物资速览（口粮/兽料/灯油/车轮耐久）、档案灯、内部通知铃铛。
   - 底部领航控制栏：实时显示当前划线草稿长度/预计耗时/物资消耗，或马车驻扎状态，提供一键出发/清空路线/扎营开演按钮。
2. **美学系统（羊皮纸质感奇幻冒险手稿 · `frontend-design` & `frontend-ui-engineering`）**：
   - **色彩令牌**：旧羊皮底 `#F3E7CE`、陈旧边缘 `#E5D2AE`、羊皮卡片 `#FAF2E0`、铁胆墨褐 `#2A1F17`、淡墨注释 `#6D5844`、烧赭框线 `rgba(110, 79, 45, 0.28)`、火漆朱红 `#A63429`、古铜琥珀 `#B87324`、钴蓝河海 `#345E7D`、浅滩青 `#5E8A9E`、松林墨绿 `#3B684B`。
   - **材质与排版**：SVG 噪点纤维羊皮纸底纹 + 边缘微焦暗角 + 衬线展示体（`Noto Serif SC / Georgia`）+ 无衬线正文（`Noto Sans SC`）+ 等宽坐标数据体（`JetBrains Mono / Consolas`）。
   - **零 Emoji 规范**：全部图标使用 `lucide-react` 矢量线框图标与定制 SVG 纹章（指南针玫瑰、火漆印章、车轮铭牌）。
   - **微交互与内部通知**：按钮按下沉降与火漆印章呼吸、标签页滑动墨迹下划线、全内部 Toast 提示条与火漆印章通知抽屉（不使用原生 alert）。
   - **全交互唯一 ID + 语义化 HTML**：`<aside>`、`<header>`、`<main>`、`<footer>`、`<nav>`、`<section>`，所有按钮/输入/卡片带清晰语义化 `id`。
3. **三级地图与 128×128 → 10× 程序化生成**：
   - **世界地图（`128×128`）**：中心连续大陆 + 四周海洋（`ocean`/`coast`）+ 离散岛屿（`island`）；9 个不规则区域通过加权噪声 Voronoi 分区铺满大陆；生成 4 条由内陆高地流向海洋的河流（`river`）与 4–5 座内陆湖泊（`lake`）。
   - **区域小地图（等比放大 `10×`）**：仅按需生成当前所在大区（及出境时懒加载相邻区）。按世界图中该区的包围盒放大 `10×`，继承不规则区域边界与海岸线；世界河流与湖泊等比放大 `10×` 并施加自然曲流扰动，保证与世界图严丝合缝；生成 1–3 座**多格占地城市**（3×3～5×5）与若干村庄，并铺设连接城市与跨区关口的主干道（`road`）与跨河桥梁（`bridge`）。
   - **侦查机制**：城市/村庄初生时只确定中心与占格范围（`scouted: false`），玩家靠近后点击侦查弹出 LLM 聚落侦查模态框（前端模拟流式推演生成地名、末世氛围、观众偏好、当地货单与 NPC 线索）。
   - **迷雾视野**：玩家仅可见当前马车实时视野圆（半径 12 格）+ 曾经走过/探明的区域（`exploredMask` 位掩码 Base64 存储，单区 ~20KB）。
   - **手动划线移动**：在「区域地图」与「跟随马车」视图上自由拖动画出墨水路线，沿线每 0.5 格采样地形计算真实行进速度、口粮/灯油/车损消耗，遇深水/海/悬崖自动红线截断；确认后沿线移动并揭露沿途迷雾。
   - **三级视图切换**：支持顶部一键切换 `世界全图` → `区域地图` → `跟随马车周边地图`。
4. **LLM 交互式前端原型界面（完整模态框/标签页）**：
   - `马车` 页：5 节车厢详情卡（升级/修理交互）、演员阵容卡片（点击打开含立绘/衣柜换装/6表情/四维/模拟「篝火夜谈 LLM 对话窗 + 视觉小说剧本切换」的角色档案模态框）、角色卡双栖导入台。
   - `物资` 页：6 大行军物资储备、奇幻生物兽笼槽位（含喂养/训练/多分支进阶树预览/拍卖行估值弹窗）、货舱货运与客厢旅客面板。
   - `记录` 页：按类型筛选的羊皮纸行旅编年日志、四大至六大势力外交与战乱态势表、可预览的「残响电台传闻」与「隐居终局筹备台」。
   - 全局模态框：叙事引擎与预设控制台（模型连接/思维链开关/词条预设外观/世界书预览）、火漆印章通知抽屉、世界手记/操作指南弹窗。

## 二、文件清单
- `src/types.ts` — 升级 `WorldMapData`、`RegionMap`、`RouteDraft`、`AppPage` 等类型
- `src/domain/worldGen.ts` — 128×128 世界地图生成（大陆/海洋/岛屿/9不规则区域/河湖）
- `src/domain/regionGen.ts` — 10× 区域放大生成（继承形状与河湖、1–3 座多格城市、道路与桥梁）
- `src/domain/routeDraw.ts` — 手动划线采样、地形速度/物资消耗、障碍截断、迷雾位图读写
- `src/rules/state.ts` / `src/rules/travelOps.ts` / `src/rules/persistence.ts` / `src/rules/act.ts`
- `src/styles/parchment.css` — 羊皮纸完整视觉令牌、排版、材质与微交互动画
- `src/components/Shell.tsx` — 侧边栏（地图/马车/物资/记录）、顶栏、底部领航条
- `src/components/Cartography/CartographyView.tsx` + `mapRenderer.ts` + `useRouteSketch.ts`
- `src/components/CaravanView.tsx` / `SuppliesView.tsx` / `RecordsView.tsx`
- `src/components/Modals/` (`ScoutDialog.tsx`, `PerformerDialog.tsx`, `EngineConfigDialog.tsx`, `BeastDialog.tsx`, `GuideDialog.tsx`)
- `tests/s2-world-region-10x.test.ts` & `tests/s2-route-draw.test.ts`
