> **当前阶段**：Superpowers Stage 1（仅输出完整书面工程计划供人工审核，**尚未修改任何业务、渲染或样式代码**）

## PLAN
════

### TASK
将游戏整体界面重构为参考图同款《八方旅人（Octopath Traveler）》全屏舆图叠层风格：把世界/区域大地图 `100vw × 100vh` 全屏常驻摊在最底层并升级为「西北斜光浮雕 + 三重海岸水波纹 + 手绘峰峦林冠笔触 + 卷云迷雾」的暖褐铜版画画风，在地图之上叠加四周巴洛克星盘雕花金框、左侧半透明炭褐尖角选单横幅、右侧半透明烟熏墨色剧团成员状态竖栏、底部纯黑键帽提示栏，以及打开子模块时透出底层山河轮廓的半透明浮层卷宗。

---

### APPROACH

#### 1. 全屏底层常驻舆图叠层架构（Map-Underneath Persistent Layering）
- **地图永远摊在最底层（`z-index: 0`）**：重构 `App.tsx` 与 `CartographyView.tsx`，无论当前处于 `地图`、`马车`、`物资` 还是 `记录` 状态，全屏舆图画布始终挂载并铺满整个主视口，不再塞进局部小卡片盒子里。
- **双态交互与精确指针分层（`pointer-events`）**：
  - 当选单停留在「大陆舆图」时，中央视野完全敞开，支持全屏拖拽划线、光标地形勘测、点击聚落菱形图标直接查看或侦查，并在顶部光晕下悬浮精巧的视距切换徽章（`1 世界全图` / `2 区域 10×` / `3 跟随大篷车`）与战区潜行开关；
  - 当选单切入「大篷车队 / 行囊兽笼 / 旅程编年」时，底层铜版画地图继续保留可见并轻微压暗，在左侧选单与右侧队伍竖栏之间的中央区域展开半透明黑褐镶金边框的古羊皮浮层面板（`#main-stage-sheet.vellum-sheet`），按 `ESC` 或点击选单「大陆舆图」即可瞬间收起浮层回到全屏大地图。

#### 2. 巴洛克星盘雕花外框与顶部暖阳金晕（`OrnateAtlasFrame.tsx`）
- 新建纯矢量高精度装饰外框组件 `src/components/OrnateAtlasFrame.tsx`（`pointer-events: none; position: fixed; inset: 0 0 var(--helm-h) 0; z-index: 18`）：
  - **顶部暖阳辐射光晕**：在星盘正下方投射参考图同款的柔金日光渐变晕染，提亮古地图中上部高光；
  - **顶部中央星盘罗盘绶带徽章（Astrolabe Crest）**：复刻参考图顶部的同心天体刻度环、放射指针与弧形铭文绶带（镌刻 `CIRCUS CARAVAN · 残响巡游舆图`），两侧延展巴洛克卷草金饰；
  - **四周双线经纬刻度金边与四角纹章**：上下左右自适应伸缩古铜鎏金双线刻槽与经纬短刻度线，左下、右下角绘制对称的狮鹫/风灯古典雕花角饰，底部正中嵌刻古典比例尺铭牌（Cartouche Scale Plaque），任意桌面宽高比下四角不变形。

#### 3. 左侧悬浮炭褐尖角选单与右侧半透明剧团状态竖栏（重构 `Shell.tsx`）
- **左侧悬浮尖角选单横幅（Octopath Chevron Menu）**：
  - 废除原先不透明封闭侧边木栏；在地图左侧（`z-index: 22`）悬浮渲染参考图同款标题 `选单` 及菱形铆钉暗纹线；
  - 下方纵向排列半透明烟熏黑褐尖角丝绸横幅（右侧裁出锐利三角矛尖 `clip-path: polygon(0 0, calc(100% - 16px) 0, 100% 50%, calc(100% - 16px) 100%, 0 100%)`，上下压细金暗线）：`大陆舆图`、`大篷车队`、`行囊兽笼`、`旅程编年`、`叙事引擎`、`测绘指南`、`归档手稿`、`随机重开`；
  - 当前激活项加深为浓墨底色、向右微探并浮现象牙白指向箭标。
- **右侧全高半透明烟熏队伍与行军账房竖栏（`RightTroupeLedger`）**：
  - 占据屏幕右侧约 `300px` 宽（`z-index: 20`），采用半透明墨褐渐变底（`rgba(18, 14, 11, 0.68)`），让底下摊开的铜版画海岸线、岛屿与山脉轮廓清晰透印出来；
  - **右上计时与账房区**：以等宽衬线数字显示 `第 X 日 · 时段`、巡游金币符号与大号金额、以及口粮/兽料/魔导灯油/车队耐久紧凑行；
  - **中部随行剧团成员状态列**：复刻参考图右侧队员排布——每位演员左侧显示带精致边框的微缩角色头像徽章，右侧分两行显示姓名、`LV. X`，以及高对比度 **翠绿体力条（HP `120 / 120`）** 与 **靛蓝士气条（SP/士气 `80 / 100`）**，点击任意成员可直接唤起篝火夜谈与换装弹窗；
  - **下部当前地域与据点侦查速览**：紧接展示当前所在大区危级、驻扎聚落侦查入口、已探明据点一键「引线」与跨区关口「出境」快捷条，无需打开大弹窗即可完成全部行军调度。
- **底部纯黑键帽操作提示栏（重构 `HelmBar`）**：
  - 屏幕最底端 `38px` 纯黑窄条（`#0d0b09`），左侧实时播报当前操作提示或已绘路线里程/消耗，右侧排列参考图同款米白立体键帽（`1/2/3` 视距 · `拖拽` 定路 · `Enter` 沿线启程 · `ESC` 返回舆图），并绑定真实全局键盘快捷键。

#### 4. 铜版画手绘立体浮雕地图渲染管线（`copperplatePainter.ts` + `mapRenderer.ts` + `mapIcons.ts`）
- 新建 `src/components/Cartography/copperplatePainter.ts`（严格控制在 `≤ 450` 行），将世界全图与 10× 区域图从「平涂彩色像素块」全面升级为参考图同款**暖褐铜版画立体古地图**，所有像素着色与矢量笔触在地图首次生成/揭雾时一次性烘焙进离屏画布缓存，保证拖拽划线 `60fps`：
  1. **古典铜版画低饱和暖褐/青灰调色盘**：陆地采用暖阳古羊皮渐变色阶（`#edd7ae` → `#d8b784` → `#be9660`），海洋与湖泊采用参考图同款低饱和灰青铜版水色（`#9ca39a` → `#828c86`），摒弃刺眼高饱和色块。
  2. **连续高度场重建与西北向斜光浮雕（NW Hillshade）**：基于地形海拔与多频噪声重建平滑高度场，计算 `(-1, -1)` 西北入射光源法线内积，使山脊西北坡泛起暖金受光面、东南坡沉淀浓褐背光暗影与山脚环境光遮蔽。
  3. **海岸三重平行水波纹墨线与海面版画排线（Triple Coastline Ripples & Sea Hatching）**：通过曼哈顿/倒角海深距离场，在距岸 `1px` 勾勒浓墨海岸线，在 `3px / 6px / 10px` 处绘制三道随波微颤的平行细墨水纹环线，并在远海叠加水平断续铜版排线，精准还原参考图海面肌理。
  4. **离屏手绘山峦脊线、林冠簇印章与石砌古道笔触**：在烘焙好的底图上按确定性网格采样：为山地簇叠加手绘人字峰峦剪影与背阴斜排线（Hachures），为森林簇点绘微缩树冠墨弧，将干道绘为双细墨虚线商道。
  5. **巴洛克卷云迷雾边缘（Cloud-Volute Fog of War）**：将区域未探索迷雾从呆板棋盘格升级为暖白羊皮云层，并在已探索与未探索交界处绘制层叠弧形卷云花边描线，呼应参考图四周云海意境。
- 升级 `src/components/Cartography/mapIcons.ts`：
  - 将城郭与村寨图标升级为《八方旅人》标志性的**双黑边象牙菱形纹章底座（Diamond Crest Pin）+ 精细城楼/木屋墨线雕刻**；
  - 为重要城郭、区域名与当前指向据点增加参考图同款的**竖向黑针引线（Vertical Black Needle）+ 半透明黑褐金字标牌与 `危级 LV.X` 侧翼徽章**；
  - 保留并精修残响大篷车专属拱顶条纹篷车 + 暖黄风灯光晕棋子图标，使其在暖褐铜版底图上成为最醒目的视觉焦点。

### EDGE CASES I WILL HANDLE
- **左右悬浮栏遮挡地图边缘出生点或城郭**：在 `computeViewport` 计算地图默认居中偏置时，感知左侧选单（约 `190px`）与右侧半透明队伍栏（约 `300px`）的安全可视中心区，使大陆主体与跟随视角下的大篷车自然落在屏幕黄金视觉中心，绝不躲进右侧半透明栏底下。
- **浮层开启时误触底层地图拖拽划线**：子模块浮层（马车/物资/记录）或模态弹窗打开时，自动屏蔽底层画布指针捕获；切回「大陆舆图」即刻无缝恢复全屏划线。
- **离屏铜版画重绘节流**：仅在世界种子切换、区域首次懒加载或玩家行军揭开新迷雾（`exploredMaskBase64` 变更）时重新烘焙离屏版画底图；鼠标悬停、划线预览、切换面板时直接复用缓存纹理，单帧绘制 `< 3ms`。
- **前序单测兼容与架构护栏**：保留 `nav-*` 唯一描述性 ID、`.silk-bookmark`、`.vellum-sheet`、`.paper-note` 等核心类名语义，确保既有 32 项单测与新增 `s4` 单测全部通过，且所有 `domain/rules` 模块体积严格 `≤ 450` 行、全界面零 Emoji。
